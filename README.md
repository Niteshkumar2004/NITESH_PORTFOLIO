# Nitesh Kumar | Portfolio

Personal portfolio of Nitesh Kumar, a Data Science graduate (B.E. CSE, Data Science, 2026) seeking Data Analyst and Data Scientist roles.

A single static page: `index.html` plus a folder of certificate images. No build step and no dependencies.

## Contents

```
index.html     the portfolio page
images/        certificate images used by the page
README.md      this file
```

## Publish with GitHub Pages

1. Create a new repository on GitHub. Name it `Niteshkumar2004.github.io` to get the address `https://niteshkumar2004.github.io`, or any other name such as `portfolio` to get `https://niteshkumar2004.github.io/portfolio`.
2. Upload `index.html`, `README.md` and the whole `images` folder to the repository root.
3. Open **Settings → Pages**, set **Source** to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then save.
4. Wait a minute or two. The live address appears at the top of the Pages settings.

## Edit

- Text and layout: open `index.html` in any editor. Colors and fonts are the variables at the top of the `<style>` block.
- Add a certificate: put the image in `images/`, then copy one `<li class="cert">` block in the Certificates section and change the file name, title, issuer and date.
